# AutoService

Консольная система управления автосервисом. Первая аттестация: Java 21, Maven, Domain, InMemory, CLI.

## Запуск

Открыть `pom.xml` в IntelliJ IDEA, выбрать JDK 21 и запустить `ru.autoservice.Main`.

Через терминал (при установленном Maven):

```sh
mvn clean verify
java -jar target/autoservice-1.0-SNAPSHOT.jar
```

Введите `help` для списка команд. После выхода данные удаляются из памяти.

## Структура

- domain — модели клиентов, автомобилей и заказов; переходы статусов.
- repository — общий интерфейс хранилища.
- inmemory — реализация через LinkedHashMap.
- service — бизнес-правила и операции.
- validation — проверка обязательных строк.
- cli — регистрация команд, ввод, вывод и обработка ошибок.
- Main — создание и связывание компонентов.

## Пример работы

Последовательно вводите команды и отвечайте на вопросы программы:

1. `customer-add` — ФИО и телефон.
2. `vehicle-add` — ID клиента (1), марка, модель, год, госномер.
3. `repair-create` — ID автомобиля (1), описание, стоимость.
4. `repair-start` — ID заказа (1).
5. `repair-complete` — ID заказа (1).
6. `history` — ID автомобиля (1).
7. `revenue` — сумма завершённых заказов.
8. `exit`.

Телефон: 7–15 цифр, допускается начальный плюс. Госномер проверяется на непустое значение и уникальность без учёта регистра. Стоимость хранится в BigDecimal, допускается не более двух значащих дробных знаков. Выручка — сумма завершённых заказов, отдельного учёта оплаты нет.

Тесты: `mvn test`. База данных и Spring не используются на первом этапе.
